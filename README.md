# 📊 SQL Sales Analysis Project

## 📌 Overview
This project is a simple SQL-based Sales Analysis System.  
It demonstrates database design, relationships, and data analysis using SQL queries.

---

## 🛠️ Tech Stack
- MySQL
- SQL

---

## 📁 Files Included
- schema.sql → Database and tables creation
- sample_data.sql → Sample data insertion
- analysis_queries.sql → Business analysis queries

---

## 🧱 Database Structure
- customers
- products
- orders
- order_items

---

## 📊 Features
- Total sales calculation
- Customer spending analysis
- Top selling products
- Daily sales report
- Multi-table JOIN operations

---

## 🚀 How to Run
1. Run schema.sql
2. Run sample_data.sql
3. Run analysis_queries.sql

---

## 🎯 What I Learned
- SQL database design
- Primary & foreign keys
- JOIN operations
- Aggregations (SUM, GROUP BY)
- Real-world analytics queries
